# Segurança

Se você encontrou uma vulnerabilidade (acesso indevido, vazamento de dados, injeção, etc.), **não abra
uma issue pública**. Use a opção "Report a vulnerability" na aba *Security* do repositório no GitHub
(aviso privado às pessoas mantenedoras). Responderemos assim que possível e daremos crédito, se você quiser.

Não teste a falha em produção além do mínimo para demonstrá-la, e não acesse dados de terceiros.
