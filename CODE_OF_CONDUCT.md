# Código de conduta

Este é um projeto sobre dinheiro público, e política desperta paixões. Aqui, o combinado é:

- **Respeito a todas as pessoas**, de qualquer partido, opinião, origem, gênero, orientação, crença ou
  deficiência. Critique ideias e dados, nunca pessoas.
- **Fatos com fonte.** Afirmações sobre agentes públicos ou empresas precisam apontar o dado oficial.
  Não use o projeto para acusar sem prova, perseguir ou expor a vida privada de ninguém.
- **Sem assédio**, ofensas, ameaças ou exposição de dados pessoais de participantes.
- **Boa-fé.** Assuma que quem discorda quer o mesmo que você: um gasto público mais transparente.

Quem mantém o projeto pode remover comentários, código ou participantes que desrespeitem estas regras.
Para relatar um problema de conduta, use o formulário de contato do site (`/contestar`) ou escreva às pessoas
mantenedoras pelo GitHub em mensagem privada.
